
# BioHeal — Agent Instructions

## Project Overview
BioHeal (bioheal.co.in) is a functional medicine & lifestyle health space. This is a Next.js 14 website with Tailwind CSS, deployed to Cloudflare Pages via GitHub Actions.

## Brand Context
- **Tagline:** "Healing Through Lifestyle, Guided by Science"
- **What it is:** A functional medicine & lifestyle health space (NOT a practice, clinic, or hospital)
- **Three Pillars:** Root-Cause Approach · Lifestyle as Medicine · Personalised Care
- **Audience:** Adults (25–55) + parents with children; urban, educated, health-aware; Bangalore & all India (virtual)

## Tech Stack
- **Framework:** Next.js 14 (App Router, Static Export)
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS with custom design tokens
- **Animations:** Framer Motion
- **Deployment:** Cloudflare Pages via GitHub Actions
- **Forms:** Formspree / Getform (no server)
- **Booking:** Cal.com (embedded widget)
- **Fonts:** Plus Jakarta Sans (headings), Inter (body), Playfair Display (accents) — via next/font/google
